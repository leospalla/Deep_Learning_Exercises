# Deep Learning for Physics — Exercises & Solutions

This repository collects my implementations, exercises, and solutions developed throughout the **Applied Deep Learning for Physics** and **Advanced Deep Learning for Physics** courses at TU Dortmund in 2026, taught by professor Christian Glaser.

The main goal of this project is to put into practice the concepts introduced during the course, exploring how machine learning and deep learning techniques can be applied to problems in physics and scientific computing.

Rather than being a collection of isolated examples, this repository is intended as a record of my learning process: from implementing fundamental concepts and algorithms to applying neural networks to physics-inspired problems and datasets.

The code and notebooks contained here were developed for **educational and study purposes**, with an emphasis on understanding the underlying methods, experimenting with different approaches, and documenting the results.
